## Содержание

- [`HR_Data_Preparation_Lab.ipynb`](HR_Data_Preparation_Lab.ipynb) — Jupyter Notebook со всеми 8 заданиями, результатами выполнения и пояснением в Markdown после каждого задания.

## Задания

1. Осмотр датасета
2. Обработка пропущенных зарплат (`errors="coerce"`, заполнение медианой, параметры `dropna()`)
3. Стандартизация названий отделов и обработка неверного возраста
4. Удаление дубликатов (`drop_duplicates()` с `subset` и `keep`)
5. Преобразование типов данных (`Int64`, `category`, числовые типы)
6. Разбор дат найма (год, месяц, день недели, стаж)
7. Переименование столбцов и объединение с таблицей отделов (`how="left"`)
8. Финальная проверка и выводы
